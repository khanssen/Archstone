Archstone Security · Research · NIST SP 800-171A Rev 2

Is the system an authoritative evidence source?

We put the question to each of the 320 assessment objectives in NIST SP 800-171A Rev 2. For 143, the system's own state answers it. For 80, the evidence exists but is conditional, a proxy, or waits on a value nobody has published. For 97, nothing the system emits answers the objective.

Standard NIST SP 800-171A Rev 2 · 320 objectives Dataset v8.9 Scope one reference environment, n=1

Authoritative evidence source, as used here: the system's own emitted state, read by a machine and compared against a referent, with no human attestation in between. A referent is the value the state is compared against, either one the Department has published or one the standard obliges the organization to set.

The limit is the referent, not the telemetry

Of the 143 objectives the system answers in full, 100 are compared against a value the Department has published. The other 43 depend on a value the organization is required to set, so the answer is only as authoritative as that value.

What these figures are. Counts from one reference environment. They show that a substantial share of the standard can be answered from the system's own state using components the standard already requires. They are not a population estimate, and a different architecture would move objectives between categories.
